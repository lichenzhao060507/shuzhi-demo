# 数改指导智能体 · Elaya-inspired 视觉改版说明

## 设计理解

产品不是智能工厂设备导购，而是一套“先诊断，再决定投入”的决策辅助工具。改版围绕 **问题识别 → 路径排序 → 政策核验** 展开。参考 Elaya 在 SaaS 落地页中重视的单一核心主张、编辑式排版、明晰的行为召唤与节制动效，未复制其具体作品。

## 主视觉

- 首页采用冷白编辑排版与右侧独立电影级工厂图版，而非文字直接压在深色照片上。
- 图片中的弧形生产线对应场景路径，聚焦的金色工位隐喻关键堵点。图片是概念配图，不是企业真实生产证据。
- 大标题只有一个承诺：“先看清企业卡在哪一步，再决定钱往哪儿投。”
- 蓝色只用于关键句与主 CTA；暖金用于现场光线和视觉隐喻，不作为数据置信度编码。
- 图签/英文字样属于设计系统，不代表新增产品功能或计算结果。

## 信息层级

1. 首屏：价值主张、两条真实入口、四个实际能力标签。
2. 方法：算分定级、查场景短板、排投入产出。
3. 开始：先试示例再填写。
4. 表单：保留现有 15 项、16 场景与经营基线。
5. 结果：诊断、改造路径、投入产出、政策四段顺序不变。

## 代码与完整性

- 原始 `index.html` 的所有 ID 都保留，额外增加了 `hero-edition`、`hero-kicker`、`hero-figure` 等**无 ID**视觉容器。
- 新增 `assets/redesign.css` 覆盖现有样式。原始 `assets/styles.css` 保留，便于对照与回退。
- `assets/app.js`、`assets/engine.js`、`data/` 完全未修改。
- 无外部 CDN。原有按钮、表单、示例与结果逻辑继续使用原 JS。

## 响应式断点

| 宽度 | 页面表现 |
| --- | --- |
| 1440px | 左侧编辑式标题区 / 右侧电影感生产线图版；下方三张独立方法卡 |
| 768px | 标题在上、图版在下；方法卡变单列，保留大图的视觉张力 |
| 390px | 按钮纵向排列，标题不强制换行，图版缩至 270px；不引入额外横向溢出 |

## 有待确认

- **视觉方向**：当前选择“浅色编辑界面 + 电影感图版”，若希望更接近参考图的深色全幅视觉，可在保持逻辑不变的前提下再做一版 A/B 对比。
- **正式上线的来源链接**：原包没有 `official/` 政策 PDF 目录，因此部分“打开原文”链接可能返回 404；上线前应补齐真实文件或核验公共官方地址。
- **ROI 解释**：保留原算法及原文案，建议在正式发布前确认区间假设与数据来源的披露是否足够醒目。
